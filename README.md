# 星穹铁道 · 银河漫游

以《崩坏：星穹铁道》为主题的 PC 端电影式互动展示网站，采用 HTML、CSS、JavaScript 和 GSAP。

在线体验：https://astral-express.tangyharp8.chatgpt.site/

## 本地运行

需要 Node.js。无需安装依赖，在项目目录执行：

```sh
npm run dev
```

打开 http://127.0.0.1:4174 。

语法检查：

```sh
npm run check
```

## 内容与交互

- 列车开场，点击后经过白光转场进入三月七主题内容。
- 11 位同行者的卡片自动轮换，并同步显示人物档案。
- 四个世界的星神与命途分隔：纳努克 / 毁灭、克里珀 / 存护、岚 / 巡猎、希佩 / 同谐。
- 世界漫游支持长按扫描：人物处显示人物信息，背景处显示场景信息；独立信息窗漂移与换位，松手收起。
- 旅途相册、深空星云尾页，以及动态效果开关。
- 仅设计 PC 端，无二级页面。

## 部署

`dist/` 是可直接部署的静态网站，包含页面与全部素材。可交给任意静态网站托管服务，设网站根目录为 `dist`，无需构建步骤。

## 目录

- `dist/index.html`：页面结构
- `dist/style.css`：视觉设计与样式
- `dist/app.js`：滚动动画与交互
- `dist/assets/`：图片、字体、视频和动画库
- `scripts/serve.mjs`：本地预览服务
